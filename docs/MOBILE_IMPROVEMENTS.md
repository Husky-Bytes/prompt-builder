# 모바일 사용성 개선 내역

대상: https://prompt-builder-blush.vercel.app/  
원본 저장소: Husky-Bytes/prompt-builder, 기준 커밋 `1b1b49f`  
작업 브랜치: `fix/mobile-usability`

## 발견한 문제와 수정

### 공통 화면
1. 반응형 규칙 없이 고정 너비와 큰 여백을 사용하던 화면에 모바일 레이아웃을 추가했다. 800px 이하에서 Builder를 한 열로 전환한다.
2. 실제로 적용되지 않던 `.app-container`를 연결하고 휴대폰의 좌우 여백을 줄였다.
3. 모바일에서는 Blocks / Builder / Library 이동 버튼을 상단에 고정해 스크롤 후에도 접근할 수 있게 했다.
4. 내보내기·가져오기·초기화를 `Data & backup`으로 접어 화면 혼잡과 초기화 오조작 가능성을 줄였다.
5. 버튼 터치 영역을 최소 44×44 CSS px로 넓혔다. 모바일 입력 글자는 16px로 설정해 iOS 자동 확대 원인을 줄였다.
6. 노치·홈 인디케이터 안전 영역, 동적 화면 높이, 터치 피드백, 모션 감소 설정을 반영했다.
7. 키보드 포커스 표시, 본문 바로가기, 현재 화면 표시, 입력 라벨과 아이콘 버튼 이름을 추가했다.
8. 긴 이름·본문을 줄바꿈하고 카드·입력창·도구 모음이 화면 너비에 맞춰 줄어들게 했다.

### Builder
9. 모바일 블록 목록은 기본적으로 접어 두고 버튼으로 열 수 있게 했다. 목록이 길면 목록 내부에서 스크롤한다.
10. 블록을 누르면 추가되며, 텍스트·블록·줄바꿈 항목 모두 위/아래 버튼으로 순서를 바꿀 수 있다. 기존 데스크톱 드래그도 유지했다.
11. 텍스트 선택 후 블록 만들기를 마우스 전용 처리에서 터치·키보드로 실행 가능한 버튼으로 변경했다.
12. 편집 도구, 미리보기, 저장 버튼, 폴더 선택을 모바일에서 줄바꿈한다. 아주 좁은 화면에서는 제목과 평점도 세로로 배치한다.
13. 텍스트 입력 높이가 내용에 맞춰 늘어나고 긴 문자열도 가로로 넘치지 않게 했다.
14. 비어 있을 때 시작 방법을 표시하고 블록 추가·순서 변경·저장 결과를 안내한다.
15. 평점은 0~100으로 제한하고, 초안 비우기는 확인 후 실행한다. 저장된 라이브러리는 유지한다.
16. 편집이 진행되면 오래된 저장·복사 성공 표시를 초기화한다.

### Blocks
17. 고정 최소 너비 320px 카드, 검색·정렬·색상 필터, 생성/편집 버튼을 반응형으로 바꿨다.
18. 색상 버튼에 이름·선택 표시·접근성 상태를 추가하고 8px 간격을 적용했다.
19. 펼치기/접기를 실제 버튼으로 바꿔 키보드와 터치로 사용할 수 있게 했다.
20. 편집 취소 후 다시 열 때 이전 미저장 입력이 남지 않게 했다. 빈 편집값은 저장할 수 없다.
21. 검색 중 전체 펼치기/접기는 검색에서 숨겨진 다른 블록의 상태를 유지한다. 검색 결과가 없으면 필터 초기화를 제공한다.
22. 저장 완료 안내와 편집 종료 후 포커스 복귀를 추가했다.

### Library
23. 고정 최소 너비 350px 카드와 폴더·정렬·이동 도구 모음을 반응형으로 바꿨다.
24. 수동 정렬에 위/아래 이동 버튼을 추가했다. 폴더 열기도 실제 버튼으로 바꿨다.
25. 폴더 안에서 검색하면 해당 폴더의 프롬프트만 검색하도록 고쳤다. 전체 화면 검색은 전체 범위를 유지한다.
26. 긴 제목·폴더명·상세 본문 줄바꿈과 중복 빈 상태 메시지를 수정했다.
27. 폴더 생성도 이름·아이콘·색상을 한 번에 설정하는 창으로 통합했다. Enter로 생성하며, 창의 화면 너비·높이·스크롤을 제한하고 Escape 닫기, 포커스 제한/복귀, 배경 스크롤 잠금을 추가했다.
28. 폴더 창을 본문 최상위에 표시해 상위 애니메이션 때문에 고정 위치가 틀어지는 문제를 예방했다.
    전체 펼치기/접기는 보이는 프롬프트에만 적용해 숨겨진 항목의 상태를 유지한다.

### 복사·저장·백업
29. 세 화면 모두 클립보드 복사 완료를 기다린 뒤에만 성공을 표시한다. 기본 API 실패/미지원 시 대체 복사를 시도하고, 그것도 실패하면 수동 복사를 안내한다.
30. 대체 복사가 끝나면 임시 입력창을 제거하고 원래 포커스와 선택 영역을 복구한다.
31. 작성 중인 제목·내용·평점·메모·폴더·편집 대상을 별도 자동 저장하고 새로고침 후 복구한다.
32. 가져오기·초기화 직후 강제 새로고침을 제거했다. React 저장이 반영되기 전에 새로고침하던 경쟁 상태를 없앴다.
33. 가져오기·초기화 후 화면 편집 상태도 초기화해 이전 입력이 새로 가져온 데이터를 덮어쓰지 않게 했다.
34. 잘못된 JSON·내부 필드·중복 ID를 검사하고 실패 시 기존 데이터를 유지한다. 기존 `blockIds` 백업을 현행 형식으로 변환한다.
35. 읽을 수 없는 기존 저장 데이터를 자동으로 덮어쓰지 않고 오류를 표시한다. 저장 용량/권한 오류도 화면에 알린다.
36. 삭제된 프롬프트·폴더를 계속 편집하거나 저장 대상으로 참조하는 상태를 정리했다.
37. 파일 읽기 실패 안내, 모바일 다운로드 URL 해제 지연, 같은 파일 재선택을 처리했다.
38. 백업은 저장된 블록·프롬프트·폴더를 포함한다는 점과, 초안은 Library에 저장한 뒤 내보내야 한다는 점을 안내한다.
39. `newline`과 작성 상태 타입을 정의하고 기존 `any` 사용을 제거했다.

## 검증

- `npm run build`: 통과 (TypeScript + Vite).
- `npm run lint`: 통과. 원본은 22개 오류가 있었다.
- `git diff --check`: 통과.
- Vercel 브랜치 미리보기 배포 성공.
- 실제 브라우저: 블록 생성·색상 지정 → Builder에 추가 → 텍스트/줄바꿈 추가 → 위/아래 순서 변경 → 미리보기 내용 확인 → 복사 결과 및 실제 클립보드 내용 확인 → Library 저장 → 목록 표시 확인.
- 실제 브라우저: 제목/텍스트를 입력하고 새로고침했을 때 작성 상태가 복구되는 것을 확인.
- 저장 로직 검증: 구형 백업 변환, 자동 저장/복구, 잘못된 백업 거부, 초기화, 삭제된 편집 대상, 손상된 저장 내용 보호, 용량 부족 안내.
- 복사 로직 검증: 기본 API 성공/거절/미지원, 대체 복사 성공/실패/예외, 포커스·선택 복원, 임시 요소 제거.
- 다른 작업자의 코드 검토에서 발견한 가져오기 후 편집값 잔존과 백업 안내 문제를 수정했다.

## 검증 범위와 반영 상태

실제 iPhone/Android의 터치·소프트 키보드·선택 메뉴는 아직 검증하지 않았다. 작은 화면은 반응형 코드와 독립 코드 검토로 확인했으며, 브라우저 환경의 화면 폭 검증에는 제약이 있었다. 실제 휴대폰에서 확인한 것으로 표현하지 않는다.

초기 검토본은 별도 브랜치 및 Vercel 미리보기에 게시했다. 이후 사용자가 모바일 드래그 수정과 운영 반영을 요청했으며, 아래 추가 수정은 같은 PR로 배포한다. 데이터 키와 기존 라이브러리 JSON 형식은 유지하고, 초안만 별도 키로 추가했다. 백업은 동일 기기의 자동 저장과 다르며 기기 간 자동 동기화 기능은 추가하지 않았다.

## 추가 수정: 모바일 드래그

원인: 기존 HTML `dragstart`/`drop` 처리에는 별도 터치 입력 처리가 없었고, 모바일 CSS는 텍스트의 드래그 손잡이를 숨겼다. 위/아래 버튼을 추가한 것만으로 손가락 드래그가 지원되지는 않았다.

40. Pointer Events 기반 드래그를 추가하고 모든 항목에 44px `⠿` 손잡이를 표시한다. 손잡이를 약 0.18초 누르거나 의도적으로 움직이면 드래그가 시작된다.
41. Builder의 텍스트·블록·줄바꿈을 손가락으로 재배열하고, Available Blocks의 블록도 원하는 위치로 끌어 넣을 수 있다.
42. Library에서 수동 순서를 드래그로 바꾸고 폴더 또는 전체 폴더로 끌어 이동할 수 있다. 화면에 표시된 정렬 순서를 기준으로 이동한다.
43. 손잡이에만 `touch-action: none`을 적용해 본문 스크롤·텍스트 선택을 유지한다. 위/아래 이동 버튼과 기존 데스크톱 드래그도 유지한다.
44. 포인터를 캡처해 손가락이 손잡이 밖으로 나가도 이동을 추적한다. 화면/목록 끝에서는 자동 스크롤하며 드롭 위치를 다시 계산한다.
45. 이동 중인 항목과 삽입 위치를 표시한다. 카드 사이 간격에서도 가장 가까운 위치로 드롭한다.
46. 손을 놓으면 한 번만 적용하고, 화면 밖·잘못된 위치·브라우저 취소·Escape·포커스 이탈·화면 전환은 안전하게 취소한다.
47. 드래그 직후 발생하는 클릭과 브라우저 기본 드래그의 중복 실행을 차단한다. 타이머·이벤트·애니메이션 프레임은 종료 시 정리한다.
48. 드래그 순서 계산과 포인터 수명 주기의 회귀 검증을 `npm test`로 실행할 수 있게 추가했다. 실제 휴대폰 하드웨어 검증과 자동화된 포인터 검증은 별개다.
